# Store trial for Roca Station 2

These are the checks that still require the actual store equipment/account. Automated tests use an isolated local database and mocked Square responses.

1. Close any older Roca Station, install the complete v2 folder and dependencies, and double-click Start Roca.vbs. Verify 2.3.1 in Chrome with no command window. Close Chrome and start again: it should reopen the same station. Save, close Chrome and use Stop Roca.vbs; confirm it reports stopped. Start again and verify saved receipts remain.
2. Create an admin password, enter a sandbox token, test locations and save. Close Admin. Verify it requires the password again and the operator screens never display the token. Restart the app and verify settings persist.
3. In Process cards, import a batch and verify there is no inventory prompt before review. Export a small Roca batch with duplicate copies and at least two finishes. Open the draft, separate one copy, correct its finish/condition/price, and mark the included cards checked. Continue to Finish and choose Create labels only. Select Next batch and verify a fresh import screen, then check a different batch and verify its Finish choice starts blank.
4. Generate side-fold labels only. Verify 2″ × 1″ physical dimensions, set/number/condition/finish/price on the left, code on the right, and a flat code after folding on a sleeve. Use the actual printer DPI and Actual size/100% printing.
5. Scan one code into the actual Square register with the shop’s scanner. Confirm it selects the correct variation; PDF software decoding alone does not prove this.
6. Reopen the test batch from Batch history, choose View this batch and Continue, then add those copies in Sandbox. Compare added quantities and variation tracking. Repeat Receive on the same receipt and confirm it adds nothing. Use Batch options to move the receipt between workflows and reprint; confirm stock stays unchanged.
7. Exercise an accepted trade-in, view its acceptance record, and verify no payment/credit is issued by the app. Verify an unaccepted trade-in cannot receive stock or retail labels.
8. Prepare a display-case listing batch and a dedicated-bin batch. Check location fields on the CSV/ticket. These files are review aids, not automatic marketplace listings.
9. Set up automatic pickup using Use Downloads folder or the browser’s actual Roca export folder. Verify old CSVs are skipped, then click Export in Roca and check the new unchecked draft opens without any import action. Export a second file while editing; it must queue without changing the editor. Next batch opens it. Restart and verify waiting drafts and exports saved while closed are retained. Copy/rename the same file: no new batch or stock. Check partial downloads, uppercase CSV, locked files and a bad CSV alongside a valid export. Review corrected/cumulative exports for overlap manually.
10. Once Sandbox behavior is confirmed, configure the real Production store. Start with a small controlled receipt and sale, checking stock at the actual location and using the catalog variation rather than a custom amount. Direct Zebra printing and marketplace synchronization are separate work.

Keep station_data and outputs with the installation. Back up while the station is closed. Do not wipe receipt history or create a new receipt to bypass a pending Square operation.

11. Delete an unreceived test receipt and restore it by reimporting its CSV. Verify it keeps the same ID and inventory choice. In Sandbox, delete and restore a received test receipt and verify it cannot add stock again. Confirm unresolved receiving cannot be deleted. Next batch and automatic pickup must not reopen old received receipts. Only pending automatic drafts should open automatically.

12. On Windows, start with the small updater ZIP and select an older test installation. Save and close the browser, then choose Update & reopen Roca. If the old console is detected, close it and confirm the updater resumes. Verify the timestamped backup, installed version, retained receipts/admin connection and Chrome reopening. Run Update Roca.vbs again and confirm an unchanged revision is reported as current without installing packages again. Native Windows launcher/Tk/file-lock behavior still requires this equipment check.

13. On a blank Process cards workspace, use Add item for a PSA 10 card at $85.13. Verify no CSV is needed, the exact cents remain, the grade appears on a side-fold label and the Square variation is tracked at that price. Repeat submission/reprint without extra stock. Add a manual item to an unfinished scanned trade-in: its selling price must use the normal cash/credit percentages. Verify the original scanned rows stay intact and accepted/received batches reject further additions. Test PSA 9 versus PSA 10 identities, cancellation and phone-size dialog scrolling.

14. In Add item, enter a Pokémon slab and use Compare prices before adding it. Verify eBay sold and current links are separate, PriceCharting opens its guide search, and TCGplayer is labeled a raw-card reference. Select Magic and check that searches use that game. Return to the item without losing the price/details. Repeat from the card editor and with a phone-size browser. These are source searches only: no live prices should be displayed as verified and no price, purchase or stock change should occur merely from opening the links.
